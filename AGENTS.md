# Project Instructions

## Important

Do not read .env, use .env.example always.

## Source of Truth

The implementation plan is documented in `IMPLEMENTATION_PLAN.md`.

For any implementation task:

1. Read `IMPLEMENTATION_PLAN.md` before making changes.
2. Treat it as the source of truth unless the user explicitly overrides it.
3. Implement one task at a time.
4. Mark completed tasks if requested.
5. If a requested change conflicts with the plan, explain the conflict before proceeding.
6. Do not invent architecture outside the plan.
